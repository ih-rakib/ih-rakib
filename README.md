## Production systems

Two internal tools built as sole developer, live in daily use at Clifton Apparels Ltd:

- **Dye Recipe Generator** (v1.3.2) — Offline-first Electron desktop app automating dyeing recipe generation:
  recipe codes, chemical formulations, dyeing + finishing sheets, unique print serials,
  history archive, admin-gated cost panel. SQLite (better-sqlite3), auto-update across multiple PCs.
  [User guide](https://docs.google.com/presentation/d/1fe_SictL4NiwzIh1-67l4epQPEXYk_Q6/edit?usp=drive_link&ouid=106196209565723480220&rtpof=true&sd=true)
- **GMatrix — Production Tracker** — Cross-department reconciliation across merchandising, store,
  cutting, sewing, finishing, and quality. Vanilla JS (ES modules, zero build) + Supabase
  (PostgreSQL, RPC, Realtime), live KPI dashboard, role-based entry.
